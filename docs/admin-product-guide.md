# Admin Product Management Guide

관리자는 Supabase 대시보드에서 직접 상품 데이터를 추가/수정합니다. 아래 절차를 따르면 애플리케이션이 기대하는 스키마(`products` 테이블)에 맞춰 안전하게 데이터를 관리할 수 있습니다.

## 1. 준비 사항

- Supabase 프로젝트에 대한 대시보드 접근 권한
- 생성하려는 상품 이름, 카테고리, 가격, 재고 수량, 통화 정보 (기본 `KRW`)
- 필요 시 slug(상품 상세 URL에 사용)를 선별해 두면 좋습니다. 미입력 시 자동 UUID 주소 사용됩니다.

## 2. 상품 등록 절차

1. Supabase Dashboard → `Table Editor` → `products` 테이블 진입
2. **New Record** 버튼 클릭
3. 다음 필드를 입력합니다:
   - `name` *(필수)*: 상품명 (50자 내외 권장)
   - `slug`: SEO 친화 URL. 영문 소문자 + 하이픈 사용 (`wireless-earbuds` 등)
   - `description`: Markdown 없이 순수 텍스트로 작성. 줄바꿈은 `Shift+Enter`
   - `price` *(필수)*: 숫자만 입력 (예: `89000`)
   - `currency`: 미입력 시 기본값 `KRW`
   - `category`: 소문자/스네이크케이스 또는 영문 소문자 권장 (`electronics`, `home_decor` 등)
   - `inventory_quantity` *(필수)*: 0 이상 정수. 0이면 일시 품절로 표시됨
   - `is_active`: 판매 중 여부. 기본값 `true`
4. **Save** 클릭 → 성공 메시지 확인

## 3. 수정/비활성화

- 가격 변경, 재고 조정 시 `inventory_quantity`와 `price`만 수정해도 UI에 즉시 반영됩니다.
- 판매 중단은 `is_active`를 `false`로 변경하면 목록 및 상세 페이지에서 숨겨집니다.
- 카테고리명을 오타로 입력하면 필터에 그대로 노출되므로 대소문자/스펠링을 사전에 정리하세요.

## 4. 품질 점검 체크리스트

- **Slug 중복**: 동일 slug가 존재하면 저장 시 오류 발생. 저장 전 검색으로 확인
- **가격 통화**: 해외 통화 사용 시 `currency`에 ISO 4217 코드 입력 (예: `USD`, `JPY`)
- **재고 경고**: 재고 5 미만이면 상세 페이지에서 "품절 임박"으로 표시되므로, 의도와 일치하는지 확인
- **설명 누락**: 미입력 시 "곧 업데이트" 안내가 표시되니, 출시 전 최소 설명 작성 권장

## 5. 테스트 권장 시나리오

1. 새 레코드 등록 → `/products` 목록에서 최신 상품 상단 노출 확인
2. 동일 카테고리 2개 이상 생성 → 상세 페이지 하단 "관련 상품" 노출 확인
3. `inventory_quantity`를 0으로 설정 → 상세 페이지 배지가 "일시 품절"로 바뀌는지 검증

필요 시 이 가이드를 업데이트해 관리자 온보딩 문서로 공유하세요.
