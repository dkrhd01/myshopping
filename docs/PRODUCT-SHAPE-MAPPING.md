## 🎯 작동 방식

### 자동 감지
```typescript
상품명 또는 slug에 키워드가 포함되면 자동으로 해당 모양 적용

예시:
- "프리미엄 패딩 점퍼" → 점퍼 모양 (넓은 타원)
- "wireless-earbuds" → 헤드셋 모양 (작은 원형)
- "슬림핏 치노 팬츠" → 바지 모양 (긴 타원)
```

### 우선순위
1. 상품명 (한글)
2. slug (영문)
3. 기본값

## 🔧 새로운 모양 추가하기

`components/lookbook/interactive-lookbook.tsx`의 `getProductShape` 함수에 추가:

```typescript
// 가방 - 정사각형에 가까운 모양
if (name.includes('가방') || name.includes('백팩') || slug.includes('bag') || slug.includes('backpack')) {
  return {
    path: "M 70 20 Q 100 25, 110 70 Q 100 115, 70 120 Q 40 115, 30 70 Q 40 25, 70 20 Z",
    width: 120,
    height: 120,
  };
}

// 모자 - 작은 납작한 타원
if (name.includes('모자') || name.includes('캡') || slug.includes('hat') || slug.includes('cap')) {
  return {
    path: "M 70 50 Q 100 52, 105 70 Q 100 88, 70 90 Q 40 88, 35 70 Q 40 52, 70 50 Z",
    width: 100,
    height: 80,
  };
}
```

## 🎨 모양 커스터마이징

### SVG Path 수정

각 모양의 path를 수정하여 더 정교하게 조정할 수 있습니다:

```typescript
// 기존
path: "M 70 40 Q 95 45, 100 70 Q 95 95, 70 100 Q 45 95, 40 70 Q 45 45, 70 40 Z"

// 더 둥글게
path: "M 70 35 Q 100 40, 105 70 Q 100 100, 70 105 Q 40 100, 35 70 Q 40 40, 70 35 Z"

// 더 각지게
path: "M 70 40 L 100 50 L 105 70 L 100 90 L 70 100 L 40 90 L 35 70 L 40 50 Z"
```

## 💡 팁

### 1. 테스트
브라우저에서 각 상품에 마우스를 올려 모양 확인

### 2. 조정
위치가 안 맞으면 SQL로 `position_x`, `position_y` 조정

### 3. 색상
모든 상품이 같은 파란색 사용 (변경 가능)

### 4. 크기
각 상품의 `width`, `height` 값을 조정하여 영역 크기 변경
