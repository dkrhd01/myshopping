# 📝 마우스로 상품 위치 조정하기

## 🎯 편집 모드 사용법

이제 마우스로 드래그해서 상품 위치를 직접 조정할 수 있습니다!

---

## 🚀 편집 모드 활성화

### 1단계: URL에 파라미터 추가

```
http://localhost:3000/?edit=true
```

`?edit=true`를 URL 끝에 추가하면 편집 모드가 활성화됩니다.

---

## 🖱️ 사용 방법

### 1. 편집 모드 켜기
- "BEST CODY" 제목 옆에 **"편집 모드"** 버튼이 보입니다
- 버튼을 클릭하여 편집 모드를 활성화하세요

### 2. 상품 드래그
- 각 상품 영역을 **마우스로 드래그**하여 원하는 위치로 이동
- 상품 이름과 현재 좌표가 표시됩니다
- 실시간으로 위치가 변경됩니다

### 3. SQL 복사
- 모든 위치 조정이 끝나면 **"SQL 복사"** 버튼 클릭
- SQL이 클립보드에 자동으로 복사됩니다
- 브라우저 콘솔(F12)에서도 SQL을 확인할 수 있습니다

### 4. Supabase에서 실행
- Supabase Dashboard → SQL Editor
- 복사한 SQL을 붙여넣고 실행
- 페이지 새로고침하면 새 위치가 적용됩니다

---

## 📋 단계별 가이드

```
1. http://localhost:3000/?edit=true 접속

2. "편집 모드" 버튼 클릭
   ↓
3. 상품들을 드래그하여 원하는 위치로 이동
   (헤드셋, 점퍼, 바지 등)
   ↓
4. "SQL 복사" 버튼 클릭
   ↓
5. Supabase Dashboard → SQL Editor에서 붙여넣기 & 실행
   ↓
6. 페이지 새로고침 (F5)
   ↓
✅ 완료! 새 위치가 저장되었습니다
```

---

## 🎨 편집 모드 기능

### 드래그 중 표시
- 상품 이름이 파란색 박스로 표시
- 실시간 좌표 표시 (x%, y%)

### 개별 드래그
- 각 상품을 드래그할 때마다 콘솔에 SQL 출력
- 한 개만 수정하고 싶으면 개별 SQL 사용 가능

### 전체 저장
- "SQL 복사" 버튼으로 모든 변경사항을 한 번에 저장
- 클립보드에 자동 복사

---

## 💡 팁

### 정확한 위치 조정
1. 드래그로 대략적인 위치 조정
2. 콘솔에서 SQL 확인
3. 필요하면 숫자 미세 조정
4. Supabase에서 실행

### 실수했을 때
- 페이지 새로고침 (F5)하면 원래 위치로 돌아갑니다
- SQL을 실행하기 전까지는 DB에 저장되지 않습니다

### 빠른 작업
- 여러 상품을 한 번에 조정
- "SQL 복사" 한 번으로 모두 저장

---

## 🔧 트러블슈팅

### 편집 모드 버튼이 안 보여요
- URL에 `?edit=true`가 있는지 확인
- 페이지 새로고침

### 드래그가 안 돼요
- "편집 모드" 버튼이 파란색인지 확인
- 클릭하여 활성화

### SQL이 클립보드에 복사 안 돼요
- 브라우저 콘솔(F12)을 열어서 SQL을 직접 복사

### 위치가 이상해요
- 페이지 새로고침 후 다시 시도
- 콘솔에서 SQL 확인하여 수동으로 조정

---

## 🎯 예시: 헤드셋 위치 조정

1. `http://localhost:3000/?edit=true` 접속
2. "편집 모드" 클릭
3. 헤드셋을 모델의 오른손으로 드래그
4. "SQL 복사" 클릭
5. Supabase에서 실행:

```sql
UPDATE public.lookbook_items li
SET position_x = 35.5, position_y = 48.2
FROM public.lookbooks lb, public.products p
WHERE li.lookbook_id = lb.id 
  AND li.product_id = p.id
  AND lb.title = '올인원 스타일'
  AND p.slug = 'wireless-earbuds';
```

6. 페이지 새로고침 → ✅ 완료!

---

## ⚠️ 주의사항

- **편집 모드는 개발용**입니다
- 프로덕션에서는 `?edit=true` 파라미터 제거
- SQL 실행 전에 백업 권장
- 여러 명이 동시에 편집하면 충돌 가능

---

이제 SQL을 직접 작성하지 않고 마우스로 편하게 위치를 조정할 수 있습니다! 🎉
