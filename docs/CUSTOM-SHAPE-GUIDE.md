# 🎨 직접 영역 그리기 가이드

이제 마우스 클릭으로 원하는 모양의 영역을 직접 그릴 수 있습니다!

---

## 🚀 사용 방법

### 1단계: 편집 모드 활성화

```
http://localhost:3000/?edit=true
```

### 2단계: 영역 편집 시작

1. "편집 모드" 버튼 클릭
2. 치노팬츠(또는 수정하고 싶은 상품) 영역 위의 **"영역 편집"** 버튼 클릭
3. 🎨 영역 편집 모드 활성화!

---

## 🖱️ 영역 그리기

### 클릭으로 점 찍기
- 이미지를 **클릭**하여 영역의 윤곽선을 그립니다
- **빨간 점**과 **번호**가 표시됩니다
- 최소 **3개 이상**의 점이 필요합니다

### 실시간 미리보기
- 점들이 **파란색 점선**으로 연결됩니다
- 3개 이상일 때 **닫히는 모양**을 미리 볼 수 있습니다

### 예시 (바지 그리기)
```
1. 허리 왼쪽 클릭
2. 허리 오른쪽 클릭
3. 오른쪽 엉덩이 클릭
4. 오른쪽 허벅지 클릭
5. 오른쪽 무릎 클릭
6. 오른쪽 발목 클릭
7. 왼쪽 발목 클릭
8. 왼쪽 무릎 클릭
9. 왼쪽 허벅지 클릭
10. 왼쪽 엉덩이 클릭
```

---

## ⚙️ 컨트롤

### 마지막 점 삭제
- **"마지막 점 삭제"** 버튼: 실수한 점 제거

### 완료
- **"완료"** 버튼: 영역 그리기 완료
  - 최소 3개 이상의 점이 있어야 활성화
  - SVG path 코드가 콘솔(F12)에 자동 출력

### 취소
- **"취소"** 버튼: 영역 편집 취소하고 위치 편집 모드로 복귀

---

## 📋 완료 후

### 1. 브라우저 콘솔 확인 (F12)

콘솔에 아래와 같은 코드가 출력됩니다:

```typescript
// 슬림핏 치노 팬츠의 커스텀 영역
if (name.includes('슬림') || slug.includes('chino')) {
  return {
    path: "M 30 20 L 35 15 L 40 20 L 45 30 ... Z",
    width: 100, // 필요시 조정
    height: 100, // 필요시 조정
  };
}
```

### 2. 코드 적용

1. `components/lookbook/interactive-lookbook.tsx` 파일 열기
2. `getProductShape` 함수 내부에 생성된 코드 붙여넣기
3. `width`와 `height` 값을 적절히 조정 (영역 크기)

### 3. 코드 삽입 위치

```typescript
const getProductShape = (productName: string, productSlug: string | null) => {
  const name = productName.toLowerCase();
  const slug = productSlug?.toLowerCase() || '';

  // 여기에 커스텀 영역 코드 붙여넣기!
  if (name.includes('슬림') || slug.includes('chino')) {
    return {
      path: "M 30 20 L 35 15 ... Z", // 콘솔에서 복사한 path
      width: 400,  // 적절한 크기로 조정
      height: 400, // 적절한 크기로 조정
    };
  }

  // 헤드셋/이어폰 ...
  // 기존 코드들
}
```

### 4. 페이지 새로고침

파일을 저장하고 브라우저를 새로고침하면 새 영역이 적용됩니다!

## 💡 팁

### 정확한 영역 만들기
- **점을 많이 찍을수록** 정확한 모양 가능
- **바지**: 10~15개 점 권장
- **점퍼**: 8~12개 점 권장
- **신발**: 6~8개 점 권장

### 실수했을 때
- **"마지막 점 삭제"**: 한 개씩 삭제
- **"취소"**: 처음부터 다시 시작

### 다리를 벌린 바지 그리기
```
1. 허리 중앙 왼쪽
2. 허리 중앙 오른쪽
3. 오른쪽 엉덩이
4. 오른쪽 허벅지 바깥
5. 오른쪽 무릎 바깥
6. 오른쪽 발목 바깥
7. 오른쪽 발 앞
8. 양 다리 사이 (가랑이)
9. 왼쪽 발 앞
10. 왼쪽 발목 바깥
11. 왼쪽 무릎 바깥
12. 왼쪽 허벅지 바깥
13. 왼쪽 엉덩이
```

### Width/Height 조정
- 영역이 너무 작으면: 값을 크게 (예: 200 → 400)
- 영역이 너무 크면: 값을 작게 (예: 400 → 200)
- 가로 세로 비율: 실제 상품 비율과 비슷하게

## 🎯 실전 예제

### 1. 치노팬츠 영역 그리기

1. `http://localhost:3000/?edit=true` 접속
2. "편집 모드" → 치노팬츠의 "영역 편집" 클릭
3. 바지 윤곽을 따라 클릭 (10~15개 점)
4. "완료" 클릭
5. 콘솔(F12)에서 코드 복사
6. `interactive-lookbook.tsx`에 붙여넣기
7. 새로고침 → ✅ 완료!

---

## ⚠️ 주의사항

- 영역 편집 중에는 **위치 이동 불가**
- 영역 편집을 완료하거나 취소해야 다시 위치 편집 가능
- SVG path는 **퍼센트(%)** 좌표로 저장되어 반응형으로 작동
- 코드를 직접 붙여넣어야 영구적으로 적용됨
