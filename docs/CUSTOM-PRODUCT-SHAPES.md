## 🎯 상품별 모양 적용하기

`components/lookbook/interactive-lookbook.tsx`에서:

```typescript
// 상품 타입에 따라 다른 path 반환
const getProductPath = (productName: string) => {
  if (productName.includes('헤드셋') || productName.includes('이어폰')) {
    return "M 70 30 Q 100 40, 105 70 Q 100 100, 70 110 Q 40 100, 35 70 Q 40 40, 70 30 Z";
  }
  if (productName.includes('점퍼') || productName.includes('후드')) {
    return "M 70 20 Q 120 30, 130 80 Q 120 130, 70 140 Q 20 130, 10 80 Q 20 30, 70 20 Z";
  }
  if (productName.includes('바지')) {
    return "M 70 10 Q 100 30, 105 80 Q 100 130, 70 150 Q 40 130, 35 80 Q 40 30, 70 10 Z";
  }
  if (productName.includes('신발')) {
    return "M 70 50 Q 110 55, 120 80 Q 110 105, 70 110 Q 30 105, 20 80 Q 30 55, 70 50 Z";
  }
  // 기본 타원형
  return "M 70 10 Q 110 20, 120 60 Q 130 100, 100 140 Q 70 155, 40 140 Q 10 100, 20 60 Q 30 20, 70 10 Z";
};

// 사용
<motion.path
  d={getProductPath(product.name)}
  // ... 나머지 속성
/>
```

## 🖌️ SVG Path 이해하기

### 명령어
- `M x y`: 시작점으로 이동
- `Q x1 y1, x y`: 곡선 그리기
- `Z`: 경로 닫기

### 예시: 타원 만들기
```
M 70 10          (위쪽 시작)
Q 110 20, 120 60 (오른쪽 위 곡선)
Q 130 100, 100 140 (오른쪽 아래 곡선)
Q 70 155, 40 140 (아래 곡선)
Q 10 100, 20 60  (왼쪽 아래 곡선)
Q 30 20, 70 10   (왼쪽 위로 돌아옴)
Z                (닫기)
```

## 🎨 색상 커스터마이징

### 테두리 색상 변경
```typescript
stroke: 'rgba(59, 130, 246, 0.6)'  // 파란색 (현재)
stroke: 'rgba(236, 72, 153, 0.6)'  // 핑크색
stroke: 'rgba(16, 185, 129, 0.6)'  // 초록색
stroke: 'rgba(245, 158, 11, 0.6)'  // 주황색
```

### Glow 효과 강도
```typescript
filter: 'drop-shadow(0 0 8px rgba(...))'  // 약한 glow
filter: 'drop-shadow(0 0 20px rgba(...))'  // 강한 glow
```

## 🔍 실제 누끼 데이터 사용

만약 실제 상품의 정확한 윤곽선이 필요하다면:

1. **이미지 편집 툴 사용**
   - Photoshop: Pen Tool로 경로 추출
   - Figma: Vector Networks로 트레이스
   - Inkscape: 무료 벡터 편집

2. **SVG 경로 추출**
   - 편집 툴에서 SVG 내보내기
   - `<path d="...">` 부분 복사

3. **코드에 적용**
   - 위의 `getProductPath` 함수에 추가

## 💡 빠른 팁

### 더 자연스러운 효과
- 각 상품마다 다른 색상 사용
- 애니메이션 속도 다르게 설정
- 크기를 상품 종류에 맞게 조정

### 단순화
- 모든 상품을 원형으로 (가장 심플)
- 크기만 다르게 (헤드셋 작게, 점퍼 크게)
